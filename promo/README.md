# فيديو إعلاني لعناياتي

`enayati-promo-vertical.mp4`: فيديو إنفوجرافيك طولي (1080×1920، 30 إطاراً/ث، 1:47 دقيقة) بدون تعليق صوتي. يعتمد على موسيقى مولّدة (112 نبضة/دقيقة) بمقدمة ثم إيقاع أساسي ثم تصاعد قبل الدعوة للتجربة، مع مؤثرات صوتية ونصوص على الشاشة. تبدأ المشاهد على الإيقاع، وفي كل انتقال ومضة ضوء وشريط لامع.

`stems/`: الموسيقى والمؤثرات كمسارين منفصلين (WAV بدقة 24 بت و48 كيلوهرتز)، للضبط في أي برنامج صوت.

## المشاهد
المقدمة ← المشكلة ← الحل ← الحجز في 4 خطوات ← الأقرب إليّ ← نظام الدور ← العربون الذكي وسجل الالتزام ← الحجز الهاتفي ← التواصل ← المنتجات ← الرضا والولاء ← تأكيد الحجز وتغيير الموعد ← تطبيق خاص لكل صالون ← المزايا التنافسية ← الدعوة لتجربة مجانية 14 يوماً

## طريقة الإنتاج (`source/`)
- **النص:** `lines.txt` بالتشكيل الكامل لنطق أوضح
- **التعليق الصوتي (النسخة السابقة، لم يعد مستخدماً):** Piper (صوت `ar_JO-kareem-medium`) يعمل محلياً، وتم التحقق من وضوحه بتحويل الصوت إلى نص عبر Whisper (`asr.py`)
- **المشاهد:** `index.html` بحركات CSS مرتبطة بتوقيت كل كلمة في التعليق، وتُلتقط إطاراً إطاراً بـ Playwright (`render.js`)
- **الموسيقى والمؤثرات:** مولّدة بالكامل برمجياً (`audio2.py`، وتبني على `audio.py`)، بلا أي مواد محفوظة الحقوق
- **الخطوط:** IBM Plex Sans Arabic و Readex Pro (رخصة OFL)
