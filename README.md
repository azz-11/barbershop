# عناياتي

تطبيق ويب بسيط لحجز مواعيد الحلاقة والصوالين الرجالية والنسائية، ويتلوّن بهوية كل صالون (علامته التجارية).

## الواجهات

- **الواجهة الترحيبية:** الشعار مع عبارة "أناقتك على موعد". أول مرة تنتظر زر "ابدأ الآن"، وبعدها تظهر لحظة قصيرة عند كل فتح
- **الرئيسية:** تحية باسم المستخدم، بطاقة الموعد القادم، والصوالين
- **مواعيدي:** القادمة والسابقة والملغاة
- **حسابي:** البيانات الشخصية، عدد الزيارات، المواعيد القادمة، إجمالي الإنفاق، نقاط الولاء، الصالون المفضل، الخدمة الأكثر طلباً، آخر زيارة، وبرنامج ولاء (خصم ٢٠٪ كل ٥ زيارات)
- **الوضع الليلي والنهاري:** زر سريع في أعلى كل صفحة، وخيارات نهاري / ليلي / تلقائي في "حسابي"

## النظام: ثلاث واجهات وطبقة بيانات واحدة

| الواجهة | الرابط | لمن |
|---|---|---|
| **تطبيق العميل** | `./` أو `./?s=<معرّف الصالون>` | العملاء: يتصفحون ويحجزون |
| **لوحة الصالون** | `dashboard.html` | صاحب الصالون: الحجوزات، الخدمات والأسعار، الفريق، الساعات وأيام الإغلاق، الهوية، كلمة المرور |
| **إدارة عناياتي** | `admin.html` | صاحب المنصة: إضافة صالون، إيقافه وتفعيله، إخفاؤه من القائمة، وأرقام كل صالون |

**طريقة العمل:**
1. تضيف صالوناً من **إدارة عناياتي**، فيحصل على رابط حجز ولوحة وكلمة مرور
2. صاحب الصالون يدخل **لوحته**، ويضيف خدماته وأسعاره وفريقه وساعاته
3. العميل يفتح **رابط الصالون** ويحجز بالاسم ورقم الجوال، ولا يمكن حجز نفس الوقت مع نفس المختص مرتين
4. يظهر الحجز في **لوحة الصالون**، فيسجّل الحضور أو عدم الحضور أو يلغي، ويرى العميل الحالة في "مواعيدي"

## نموذج العمل: اشتراك لكل صالون

كل صالون يشترك **شهرياً أو سنوياً**، ويحصل في الاشتراك على:
- **تطبيقه الخاص:** رابطه، هويته وألوانه، أيقونته عند التثبيت، وبطاقة QR
- **لوحة الإدارة:** الحجوزات، الخدمات، الفريق، والإعدادات
- **الظهور في منصة عناياتي** لعملاء جدد

| الحالة | ماذا يحدث |
|---|---|
| **تجربة مجانية** | تبدأ تلقائياً عند إضافة الصالون (14 يوماً افتراضياً) |
| **مشترك** | كل شيء يعمل |
| **ينتهي قريباً** | تنبيه في لوحة الصالون قبل الانتهاء بـ 5 أيام |
| **فترة سماح** | بعد الانتهاء يبقى الحجز يعمل أياماً قليلة (3 افتراضياً) مع تنبيه |
| **منتهٍ** | يتوقف الحجز ويختفي الصالون من المنصة تلقائياً، حتى يُجدَّد |

**التجديد:** صاحب الصالون يختار الباقة من "الإعدادات ← اشتراكي"، ويحوّل المبلغ، ويرسل طلب التجديد. تؤكده من **إدارة عناياتي** فيتمدد الاشتراك ويعود الصالون تلقائياً. ويمكنك أيضاً تسجيل دفعة يدوياً (نقداً أو تحويل أو بطاقة).
**الأسعار** وأيام التجربة والسماح وبيانات الحساب البنكي تُعدَّل من إدارة عناياتي.
الأسعار الحالية (199 شهرياً و1990 سنوياً) **افتراضية** للتجربة.

**طبقة البيانات** (`js/store.js`): كل الواجهات تقرأ وتكتب من خلالها فقط، وكل حجز مربوط بصالونه.
حالياً تحفظ في متصفح الجهاز، لذلك تعمل التجربة على **نفس الجهاز والمتصفح** فقط. عند ربط قاعدة بيانات حقيقية تُستبدل هذه الطبقة وحدها، وتبقى الواجهات كما هي.

**كلمات المرور التجريبية:** لوحة كل صالون `1234`، والإدارة `admin`. هذه للتجربة فقط، وتُستبدل بتسجيل دخول حقيقي مع قاعدة البيانات.

## وضعان في تطبيق واحد

| الرابط | ماذا يرى العميل |
|---|---|
| `https://azz-11.github.io/barbershop/` | **منصة عناياتي:** كل الصوالين |
| `https://azz-11.github.io/barbershop/?s=sanad` | **تطبيق صالون سَنَد وحده:** شعاره وألوانه وعبارته، خدماته وأسعاره، فريقه، معلوماته وموقعه، وحجوزاته فقط |

في وضع الصالون، يظهر اسم الصالون وأيقونته عند تثبيت التطبيق على الجوال، ويظهر في الأسفل "يعمل بواسطة عناياتي".
روابط الصوالين الحالية: `?s=sanad` و `?s=qass` و `?s=maha` و `?s=lulu`

لإخفاء صالون من قائمة المنصة (للتجربة) مع بقاء رابطه يعمل، أضف له `unlisted: true` في `js/data.js`.

### إضافة صالون جديد
1. أضف بياناته في `js/data.js`: المعرّف (`id`)، الاسم، العبارة (`slogan`)، النبذة (`about`)، العنوان، الألوان، الساعات، الخدمات، والفريق
2. ولّد ملفاته:
   ```bash
   cd tools && npm install && npm run salons
   ```
   فتُنشأ أيقونة التطبيق (`icons/salons/`)، وملف التثبيت (`manifests/`)، ورمز QR وبطاقة طباعة A6 بدقة 300dpi (`qr/`)
3. ادمج التعديل في `main`، وسيُنشر تلقائياً

## الخطوات

1. **اختيار الصالون** (الكل / رجالي / نسائي)
2. **اختيار الخدمة**: يمكن اختيار أكثر من خدمة، مع السعر والمدة
3. **اختيار الحلاق أو المختصة**، أو "أي مختص متاح"
4. **تحديد الموعد**: الأيام الـ ١٤ القادمة، والأوقات حسب ساعات عمل الصالون ومدة الخدمات
5. **الدفع**: Apple Pay، مدى/بطاقة، أو الدفع في الصالون
6. **تأكيد** برقم حجز، وصفحة **مواعيدي** للمتابعة والإلغاء وإعادة الحجز

## الهوية البصرية

- **الخط:** ثمانية (Thmanyah Sans). راجع [`fonts/README.md`](fonts/README.md) لطريقة تفعيله وشروط ترخيصه
- **الألوان:** بترولي `#0E4F4A` مع نحاسي `#B8893B` على أرضية فاتحة بميل أخضر. ويأخذ التطبيق ألوان الصالون المختار أثناء الحجز
- يدعم الوضع الداكن واتجاه RTL، ومصمم للجوال أولاً

## التشغيل

لا يحتاج التطبيق إلى أي تثبيت أو بناء:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر على GitHub Pages

النشر تلقائي: كل تعديل يُدمج في فرع `main` يُنسخ إلى فرع `gh-pages`، ويظهر على الموقع خلال دقيقتين تقريباً.
لا تعدّل فرع `gh-pages` يدوياً، فهو يُستبدل مع كل نشر.

رابط التطبيق: **https://azz-11.github.io/barbershop/**

## التثبيت على الجوال

- **آيفون:** افتح الرابط في Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**
- **أندرويد:** افتح الرابط في Chrome ← القائمة ⋮ ← **تثبيت التطبيق**

يعمل التطبيق بعد التثبيت بملء الشاشة، ويفتح حتى بدون إنترنت.
عند تعديل أي ملف، غيّر رقم `VERSION` في `sw.js` ليصل التحديث للمستخدمين.

## ملاحظات النسخة الحالية

- النسخة **تجريبية**: الحجوزات تُحفظ في متصفح المستخدم (localStorage)، والأوقات المحجوزة مسبقاً مولّدة للعرض
- الدفع **محاكاة** فقط، ولا يُخصم أي مبلغ

## الخطوات القادمة المقترحة

- قاعدة بيانات وخادم (مثل Supabase أو Firebase) لحفظ الحجوزات ومزامنتها مع الصالون
- لوحة تحكم لصاحب الصالون: الخدمات، المختصون، ساعات العمل، والشعار
- ربط بوابة دفع محلية (Moyasar أو HyperPay أو Tap)
- تذكير بالموعد عبر SMS أو واتساب
