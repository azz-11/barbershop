# خط ثمانية

التطبيق مصمم على خط **ثمانية (Thmanyah Sans)**.

ترخيص خط ثمانية لا يسمح بإعادة توزيع ملفاته أو استضافتها، لذلك لا توجد ملفات الخط في المستودع.
لتفعيله:

1. نزّل الخط من الموقع الرسمي: https://font.thmanyah.com
2. انسخ الملفات إلى هذا المجلد بالأسماء التالية:
   - `thmanyah-sans-Regular.woff2`
   - `thmanyah-sans-Medium.woff2`
   - `thmanyah-sans-Bold.woff2`
3. أو ثبّت الخط على جهازك فقط، وسيستخدمه التطبيق تلقائياً.

إن لم يتوفر الخط، يعرض التطبيق خط IBM Plex Sans Arabic بديلاً.

> قبل الإطلاق التجاري، راجع شروط الترخيص على https://font.thmanyah.com/licenses أو تواصل مع ثمانية على Ask@thmanyah.com.
